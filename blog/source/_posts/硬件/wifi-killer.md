# 前言

搞一个小手工，看这个最简单嗯呐，所以我就给搞了一下，并且做了出来，什么是wifikiller，利用了826.1.1wfii协议的漏洞，来攻击wfii，可以用来做些，攻击wifi

克隆wifi 的用途 （不过呢 攻击wifi这个功能在很多现在的路由器 2023.9 都已经修复了这个漏洞 所以很难再去攻击的到别人的网络）

本文章用于最简单的制作 即 单纯一个esp8266（带wifi模块） 就开干！

# 材料

1. esp8266（带wifi模块的） 即可（什么C340 01s 各种都可以的 只要带上了wifi模块即可）

————————————————————以上 和 以下 是不同的 以上是必须的 以下是无所谓的—————————————————————————

1.  pcb模板 用来固定板子
2. oled显示屏 0.94寸 四阵脚 GND在前
3. 按钮 3 +1 一个用来开关整个板子+显示屏 其余三个用于控制显示屏
4. 一个3.7V的充电模块
5. 一个3.7V的 锂电池 容量 大小不限

# 使用

在完成上述所有之后 我们给esp8266 通上电 然后我们打开wfii 可以看见一个 WI-PWN 的wifi

1. 连接WI-PWN 
   1. 连接上之后打开浏览器
2. 打开192.168.4.1
   1. 可以进入到硬盘后台
3. 然后配置一下 重新连接
4. 后面就可以直接攻击别人or 克隆wifi了

# 问题

1. 在我使用的时候 发现已经无法攻击别人了 
2. 克隆wifi信号弱
   1. 我在使用的时候克隆了别人的wifi名字 但是wifi信号特别差 几乎是4,5m的范围就搜不到信号了
   2. 如果想要增强wfii信号 就需要购买响应的支持天线的版本的 esp-07开发板
