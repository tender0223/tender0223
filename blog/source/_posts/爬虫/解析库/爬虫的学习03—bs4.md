在使用bs4 我们会需要用到一些语法来完成我们对doc文档内容的查询，

find() # 去进行查询第一个符合条件的内容就返回

find_all # 去查询所有的符合条件的内容

# 使用

和其他类型一样， bs4呢我们也是需要先将页面源代码，先存入到bs4的参数中，并且设置好你要使用的解析器 比如这里我们将会使用html的解析器来进行解析

```python
page = BeautifulSoup(response.text, 'html.parser') # 1. 传递页面源代码 2. 采用html的编译器
```

然后此时page 已经拿到了页面源代码，我们此时可以将page视为一个拥有页面源代码且提供了bs语法的一个参数，所以我们可以通过语法对这个页面进行一个搜索我们需要的内容

```
X = page.find('div',class_='main') # 这里我查询一个div 做个演示即可 这个class代表的意义是 我要搜索的这个div他的类名必须要是main
```

拿到了 一个标签为`<div class='main'>xxxxx<main>`的

这样我们就算使用成功了
