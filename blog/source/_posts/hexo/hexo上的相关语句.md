## 清理缓存 （清除本地的public）

```
hexo cl
```

作用是 将本地之前写好的public 给进行删除

## 在本地存储

```
hexo g
```

作用是 将本地上的md文件 转化成相应的html文件 并且存储在public 文件中

## 本地渲染

```
hexo s
```

将本地上的md文件进行渲染 可以看到在本地上的文件渲染之后的样子

## 文件推送

```
hexo d
```

将本地上的public 文件进行推送到你的gitee账户上

## 创建新帖子

```
hexo n md名字
```

在source上创建一个新的md文件
