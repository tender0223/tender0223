具体的操作其实简单

我在写这篇帖子的时候已经找了很多的相关帖子 他们都是有这样的一个前提要求
当然了 这段修改 是为了每次new一个新的md文件的时候会有一个相应的文件夹被创建

```
首先是在_config.yml 中找到post_asset_folder
post_asset_folder: false
将此时的false 改为true
```

那我呢就想着没有什么用处反而会让我的posts文件变的很冗长 所以我就给关闭了 发现在关闭之后 仍不会影响图片的引用(说这句话是为了让大家知道并不是一定非要开启才可以引用图片的！)

然后在回到 source 目录下 找到该目录下的images (一般情况 source目录下只有一个_posts 没有images 如果没有创建一下就可以了注意 必须是images 不能是img这样的缩写或者别名)
然后直接输入

```
![logo](images/文件名字)
```

在我这个路径下有个叫wr的图片
![比如说](D:\blog\source\_posts\PIC\2023.1.8-text.png)

我输入以下这串代码
![引入图片](D:\blog\source\_posts\PIC\2023-01-08_14-56-14-text1.png)

即可引入我的wr图片
![引入图片](D:\blog\source\_posts\PIC\wr.png)

如果是站外的图片 不在本地 则可以直接用那个图片的网络地址
