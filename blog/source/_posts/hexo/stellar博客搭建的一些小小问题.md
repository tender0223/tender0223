## 问题

1. 在使用hexo n xxx 命令 中创建md文档之后 会额外被“附赠”一个文件夹 如何关闭呢？
   1. ![image-20230825115048584](../PIC/image-20230825115048584.png)
   2. 解决方法： 在_config.yml 中找到 post_asset_folder 并改为false即可

​	

|  额外选项   |                             描述                             | 默认 |
| :---------: | :----------------------------------------------------------: | :--: |
| line_number |                           显示行号                           | true |
|  highlight  |                       启用代码高亮显示                       | true |
| fires_line  |                         指定第一行号                         |  1   |
|    mark     | 行突出显示特定的行，每个值用逗号分隔。使用破折号指定数字范围 |      |
|    wrap     |                    将代码封装在<table>中                     | true |
