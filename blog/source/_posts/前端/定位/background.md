## 关于background的用法千篇千样（写者这边仅仅着重介绍几个经常用的参数）

### == background color == 

用来给盒子赋予颜色

```
background-color: pink;
```

这里也可以用十六进制来写入颜色

```
background-color:#666;   
```

这里写入的颜色其实是 ==#666666 == 这其中有个特点就是只要六个的值是相同的即可用前三位值来进行替代，简写

是方便的写法哦

### ==background rgba()==

这个rgba 也是一种对盒子颜色的赋值

```
background: rgba(0, 0, 0, 0);
```

可以看到 rgba只有 这==三个参数== 但是我在后面缺又多写了一个0

这个最后一个零代表的是透明度

rgba(x, y ,z ,g)

x y z 分别对应三原色 取值范围都在0~255

而g 则代表的是透明度 取值范围是在0 ~ 1 取值越高 透明度则越低 反之则易然

### ==background-image: url==

如标题所言 结尾是image 可以知道 这个用来上传我们的图片 url内跟的是图片的路径

值得说的是 这个路径既可以是你本地图片的相对路径 也可以是网络上的网络路径
