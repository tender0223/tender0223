## 代码解释

```
img {
    width: 400px;
    position: fixed;
}
```

img 是我选中了body中的img标签
修改了大小 width为400px
设置了fixed布局
意思就是 这个img里面的东西 将会被固定在这个位置 不会随着页面的上下左右来回移动

而大量的div 也只是单纯的顶出浏览器的滑动 可以更加清晰看出 图片被我固定
这种方法普遍用于 一些网站用来固定小广告之类的
