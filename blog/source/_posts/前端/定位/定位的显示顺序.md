## 意义： 由于子绝父相导致儿子没有空间大小而会出现的一些图层叠加不显示的状态

### 比如说

HTML内容

```
<div>
    <div class="box1"></div>
    <div class="box2"></div>
</div>
```

CSS样式

```
div {
    position: relative;
    width: 200px;
    height: 200px;
    background-color: pink;
}
.box1 {
    position: absolute;
    width: 50px;
    height: 50px;
    background-color: red;
    top: 0;
    left: 0;
}
.box2 {
    position: absolute;
    width: 50px;
    height: 50px;
    background-color: black;
    top: 0;
    left: 0;
}
```

这样就会出现一个问题

能看的出来 我们的那个box1 “消失”了 其实不然 这是因为 box2盒子将box1压在了下面

那假如说我们需要显示box1 而不是box2呢 该怎么办呢 很简单 我们可以使用

```
z-index: 1;
```

所有图层一开始都是默认是0 但是后面的box将会覆盖在前面的box之上

而我们只需要在box1的css样式中添加上这句代码 即可将默认图层变成1 当然 你也可以写成其他的数字 可以写无穷大的哦

```
.box1 {
    position: absolute;
    width: 50px;
    height: 50px;
    background-color: red;
    top: 0;
    left: 0;
    z-index: 56151;
}
```

这样我们就会显示成红色box1了

这便就是定位的显示顺序了哦
