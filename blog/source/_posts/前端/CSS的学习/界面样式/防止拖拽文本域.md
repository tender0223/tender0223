## 开始

文章开始前 我想让各位读者明白 本帖的名字到底是什么意思 其实也很简单 就是字面意思罢了 防止文本域 被拖拽 这节 也了解的知识点相对较少 比较容易理解

我们之前在input组件里面曾经学过 textarea 这么一个元素 他这个元素就 主打的就是一个文本填入 但是细心的读者想必也已经发现了 在 textarea中的右下角呢 是有一个倾斜线的 当我们把鼠标放上去可以发小 这个文本域是可以被自由定义大小的

这样的问题是什么呢 会有一些用户在使用这个文本域的时候 不断的放大改文本域 如果我们没有写自适应窗口的话 则会破坏我们当前页面的一些摆放位置 就算是写了自适应 也仍然会导致 窗口过大 其他组件被挤丢 所以我们直接给他设定好了一个固定大小

```
textarea{
	resize: none;
}
```

这样就不会被因为自由放大缩小文本域导致页面整体组件变形了 我们可以提前进行组件大小的控制
