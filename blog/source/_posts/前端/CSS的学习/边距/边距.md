## margin 简述

margin一个很奇妙的元素 我到目前位置 都不知道该如何去解释 一个时有时无的元素

margin 是元素的外边距

![image-20230319140956555](D:\blog\source\_posts\PIC\image-20230319140956555.png)

就是不在元素范围的内 读者也可以想象成 两个人在排队 这两个人的身体大小就是该元素的 width 衣服呢就是padding 而这两者之间的距离 就是margin好 关于margin的描述其实也就是这样！ 但是值得注意的

## 使用

### margin : auto; 居中

#### 原理

就是 auto自动调整了左右margin值 使得该元素大小 左右margin值 是相同的

而 我们仍然可以继续添加元素如

```
margin: 200px auto;
```

这段代码的意思也很明确 意思就是 上下边框的值 为 2000px

左右自动调整居中

![image-20230319142821150](D:\blog\source\_posts\PIC\image-20230319142821150.png)

## margin:; 的任意使用

在很多时候 我们会用到 更多其他的设置 来进行对图片更多的操作

比如说 我想要导航栏中的![image-20230319142917434](D:\blog\source\_posts\PIC\image-20230319142917434.png)

这个效果 我们可以理顺出一个思路 即 上面这五个元素 是用li来制作 的 并且每个元素的margin值相同 来充当出一个有顺序的 有间隔的 的数个元素

开始实践

margin: 0 0 0 0 ; 里面分别有对应的四个值 分别依次对应为 上 右 下 左

如果我们只写了两个 参数 则第一个参数 就代表着 上下的margin值 第二个代表的是左右的margin值 这点在我们写 margin: 2000px auto; 中也有体现

代码示例

```
<div></div>
<div></div>
<div></div>
div {
	width: 200px;
    height: 200px;
    background-color :#666;
    float: left; /*这点其实是 对上一个浮动的复习 也是为了更好的体现出 margin值的表现*/
    margin: 20px; /* 是说这三个div 四周的边距都是20px */ 
}
```
