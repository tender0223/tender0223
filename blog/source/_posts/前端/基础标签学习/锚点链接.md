## 对比超链接 和锚点链接的区别

|      | 超链接             | 锚点链接           |
| ---- | ------------------ | ------------------ |
| 优点 | 进行html之间的跳转 | 阅读整个html的内容 |

## 锚点链接要点

内容的跳转是根据 给文本添加id然后再 使用a标签 用href去指向相应的ID
（提醒 指向iD的时候需要用 #ID 类名是用.class）
