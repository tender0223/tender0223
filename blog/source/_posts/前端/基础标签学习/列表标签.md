form 表单

```
<form action="demo_form.php" style="border: 1px solid pink;">
    First name: <input type="text" name="fname"><br>
    Last name: <input type="text" name="lname"><br>
    <input type="submit" value="提交">
</form>
```


select option 下拉菜单

```
<select>
    <option value="value的值可以随意指定这些东西在后面js jq中才有用到">1</option>
    <option value="saab">这里面是下拉菜单里面的内容</option>
    <option value="opel">如果你想则可以继续往下面添加</option>
    <option value="audi">Audi</option>
</select>
```

textarea 文本域

```
<textarea name="" id="" cols="30" rows="10"></textarea>
```

\## 无序列表

```
<ul>
    <li>这是一个列表</li>
    <li>ul里仅仅能有li</li>
    <li>但是li里面可以有任何东西</li>
    <li>相当于一个容器了</li>
    <li></li>
</ul>
```

## 有序列表

```
<ol>
    <li>这是一个列表</li>
    <li>ol里仅仅能有li</li>
    <li>但是li里面可以有任何东西</li>
    <li>相当于一个容器了</li>
    <li></li>
</ol>
```

有序和无序看起来很夸张 但是其实他们两个是相差无几的 在我们后面html的使用中呢 这两者是随机使用(在我看来)

## 自定义列表

这就有趣了(当然了仅仅有趣在可以被自定义标签)
这个列表你随意定制 他可以被你自定义成任何标签

```
<dl>
    <dt>查询我们</dt>
    <dd>百度百科</dd>
    <dd>新浪微博</dd>
    <dd>bilibili</dd>
    <dd>联系我</dd>
    <dq>123123</dq>
</dl>
```
